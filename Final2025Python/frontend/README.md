# Frontend Gaming Electronics

Aplicación React + TypeScript inspirada en MercadoLibre para consumir la API de e-commerce existente.

## Scripts
- `npm install` instala dependencias
- `npm run dev` inicia servidor de desarrollo en `http://localhost:5173`
- `npm run build` genera artefactos de producción
- `npm run test` ejecuta pruebas de cliente HTTP

## Configuración
- Define `VITE_API_BASE_URL` (por defecto `http://localhost:8000`) para apuntar a la API.

## Características
- Header sticky con botón de inicio, buscador centrado, burbuja de carrito y sesión.
- Catálogo responsivo con tarjetas minimalistas y colores azul/negro/blanco.
- Detalle de producto y carrito con control de cantidades.
- Inicio/cierre de sesión enlazado a endpoints de clientes.
